<Section label="01 · Overview" title="Your files, one scan away">

GoDrop is a local file-sharing tool I designed and built to make moving files between a computer and phone less tedious.

As a designer, I often work with exported images, PDFs and other files that I need to access on my phone. Instead of repeatedly sending files through messaging apps or relying on cloud storage, I wanted a simpler way to access them directly.

<Figure
  src="/project/drop/cover.png"
  alt="GoDrop local file-sharing interface"
  caption="GoDrop turns a folder on your computer into a browsable file portal."
/>

</Section>

<Section label="02 · The problem" title="Moving files shouldn't be this complicated">

Getting a file from a computer onto a phone often means uploading it somewhere, opening another app or repeating the process for every new export.

I wanted a workflow that felt more immediate, especially when working with multiple design files.

</Section>

<Section label="03 · The solution" title="A folder becomes a file portal">

GoDrop runs a lightweight server on the computer. The phone connects to it over the local network, using a QR code to open a browser-based interface.

From there, users can browse available files, preview and download them to their phone, or upload files back to the computer.

No dedicated mobile app, account or cloud upload is required.

</Section>

<Section label="05 · Reflection" title="Designing across the interface and the system">

GoDrop was an exercise in making an everyday technical problem feel simple. The challenge wasn't just transferring files; it was connecting networking, server behaviour and interface design into one coherent experience.

It reinforced the kind of work I enjoy most: designing the interface and engineering the system behind it.

</Section>
